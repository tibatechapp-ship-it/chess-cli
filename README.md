# Chess CLI

Terminal-based chess game in pure Python. No dependencies.

## Features

- Full 8x8 board with all 6 piece types (King, Queen, Rook, Bishop, Knight, Pawn)
- FEN notation support (`to_fen` / `from_fen`)
- Algebraic move input (`e2e4`, `e7e8Q`)
- Interactive REPL loop

## Usage


Then type moves like `e2e4` or `quit`.
